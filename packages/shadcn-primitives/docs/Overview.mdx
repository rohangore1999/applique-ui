## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `intent` | `'default' \| 'secondary' \| 'outline' \| 'ghost' \| 'destructive' \| 'link'` | `'default'` | Visual style of the button |
| `size` | `'sm' \| 'md' \| 'lg' \| 'icon'` | `'md'` | Button size |
| `className` | `string` | - | Additional classes (merged with tailwind-merge) |
| `disabled` | `boolean` | `false` | Disabled state |
| `...props` | `ButtonHTMLAttributes` | - | All standard button HTML attributes |

## Design Tokens

All colors use CSS custom properties from Figma Applique design tokens:

- `--primary`: #5232D0 (indigo/700) - Main brand color
- `--secondary`: #F0EEFF (indigo/50) - Secondary actions
- `--destructive`: #BF3823 (Cherry/700) - Destructive actions
- `--border`: #E5E7EB (gray/200) - Borders
- `--ring`: #5232D0 - Focus ring color
- `--radius`: 0.5rem (8px) - Border radius
